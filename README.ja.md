# Redmine Design Guide

[![License](https://img.shields.io/github/license/redmine-kit/design-guide?label=License)](LICENSE)

Redmine 7 の画面がどう作られているかと、Redmine 7 がテーマを適用する仕組みをまとめたガイドです。本体と同じ見た目と動きの画面を作りたいプラグインの作者と、テーマの作者のためのものです。

[English](README.md)

- **画面:** Redmine 7.0.3 の画面のパターン(画面の組み立て、一覧、情報の表示、設定、フォーム、メッセージ、アイコンとリンク、プロジェクトの設定)です。それぞれに、使っている本体のビュー、写すマークアップとヘルパー、標準のスタイルシートがそのクラスに当てるスタイル、英語と日本語のスクリーンショットを付けています。
- **テーマ:** Redmine 7 がテーマを見つけ、読み込み、適用する仕組みと、テーマが対応する必要のある項目のチェックリストです。項目ごとに、確認に使う [Redmine Lookbook](https://github.com/redmine-kit/redmine_lookbook) のプレビューを挙げています。
