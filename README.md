# Redmine Design Guide

[![License](https://img.shields.io/github/license/redmine-kit/design-guide?label=License)](LICENSE)

How Redmine 7's own screens are built, and how Redmine 7 applies a theme. For plugin authors who want screens that look and behave like core, and for theme authors.

[日本語](README.ja.md)

- **Screens:** the patterns of Redmine 7.0.3's screens (page structure, lists, information, settings, forms, messages, icons and links, project settings), each with the core views that use it, the markup and helpers to copy, what the default stylesheet does with its classes, and screenshots in English and Japanese.
- **Themes:** how Redmine 7 finds, loads and applies a theme, and a checklist of what a theme has to handle, with the [Redmine Lookbook](https://github.com/redmine-kit/redmine_lookbook) preview for each item.
